# AcheronEX

AcheronEX es un juego de palabras inspirado en Wordle. El objetivo es descubrir una palabra secreta de cinco letras en un máximo de seis intentos.

## Cómo jugar

1. Escribe una palabra de cinco letras usando el teclado de la pantalla o el teclado físico.
2. Pulsa **Enter** para comprobar tu intento. Puedes borrar letras con **Backspace**.
3. Usa los colores para ajustar tu siguiente intento: verde indica la letra correcta en su posición, amarillo indica una letra presente en otra posición y rojo indica una letra que no aparece.
4. Al terminar, consulta tus estadísticas, comparte el resultado o inicia otra partida. Las estadísticas se guardan en el navegador.
